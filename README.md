# Mystic Mayhem

Mystic Mayhem is a CLI-based text adventure game that immerses players in a world of magic, mystery, and perilous choices. Developed in Java, the game uses command-line interactions to guide players through a thrilling narrative filled with challenges and puzzles.

## Features

- **Interactive Gameplay**: Navigate the story by making strategic choices.
- **Dynamic Challenges**: Encounter puzzles, enemies, and branching storylines.
- **Multithreading**: Ensures smooth game performance with concurrent task handling.
- **Engaging Storyline**: A richly detailed fantasy world with surprises at every turn.

## Technologies Used

- **Programming Language**: Java
- **Concurrency**: Multithreading for managing game events and user inputs.
- **File Handling**: Save and load progress via text files.
- **Design Principles**: Object-oriented programming for modular and scalable code.

## Gameplay Instructions

1. Launch the game from the terminal.
2. Follow the prompts to make decisions and progress through the story.
3. Input commands to interact with the environment (e.g., `explore`, `attack`, `use item`).
4. Strategically manage resources and make decisions to survive and uncover secrets.

## Key Learnings

- Designed an interactive CLI interface with robust error handling.
- Utilized multithreading for event handling and asynchronous game mechanics.
- Implemented file I/O for game state persistence.
- Developed skills in debugging and optimizing Java applications.
